# שביל ישראל – מתכנן ומלווה המסע 🥾

אפליקציית ווב (PWA) דו-לשונית (עברית / English) לתכנון וביצוע מסע בשביל ישראל: מקטעים, לינה, מים, עונות, מפה, מצפן, GPS, יומן מסע ועוד.
עובדת בדפדפן, ניתנת להתקנה על מסך הבית בטלפון, וממשיכה לעבוד ללא אינטרנט לאחר הטעינה הראשונה.

| **יומן** | רשומות יומיות עם תמונות (נדחסות ונשמרות במכשיר), מצב רוח, מזג אוויר, לינה, ליטרים, מקטע ומיקום; גלריה; סטטיסטיקות; תעודת הוקרה להדפסה |
| **הגדרות** | מצב כהה/בהיר, מפת רקע, גיבוי/שחזור הנתונים (JSON) |
| **English UI** | כפתור EN/עב בכותרת מחליף את כל הממשק לאנגלית (כ-1,070 מחרוזות, שמות מקטעים ונקודות קצה באנגלית, תאריכים ומספרים לפי שפה, פריסה LTR). תיאורי המסלול הרשמיים של 56 המקטעים, "סיפור הדרך", "חשוב לדעת", המלצות בסביבה, אזהרות ותחבורה תורגמו לאנגלית (`scripts/i18n/spni-en/seg-NN.json`, נבדקים ב-`scripts/i18n/spni-check.py`); תקצירי ויקיפדיה של נקודות העניין ורשימת מלאכי השביל נשארים בעברית ומוצגים RTL |

כל הנתונים האישיים נשמרים במכשיר בלבד ונשארים בין פתיחות: תוכנית, יומן, התקדמות, אנשי קשר (localStorage); תמונות, תוואי השביל ומסלולי GPS (IndexedDB); אריחי מפה ותמונות ויקיפדיה (Cache API דרך ה-Service Worker). האפליקציה מבקשת אחסון קבוע (`navigator.storage.persist`), ובכל מקטע אפשר להוריד מראש את אריחי המפה (זום 11–15). גיבוי מלא כולל תמונות – בהגדרות. אין שרת.

## אבחון תקלות
`/diag.html` מציג גרסת דפדפן, יכולות נתמכות ומצב טעינת הקבצים. אם האפליקציה קורסת מוצגת הודעת שגיאה קריאה עם "נסו שוב" ו"איפוס נתונים" במקום מסך לבן.

## רענון אוטומטי

- **גרסת האפליקציה**: ה-Service Worker בודק גרסה חדשה בכל פתיחה, בכל חזרה למסך (גם כשמותקנת על מסך הבית) ואחת לשעה, ומחיל אותה מיד.
- **עדכוני תוואי**: המשימה `.github/workflows/refresh-updates.yml` רצה מדי יום, שולפת את עמוד העדכונים של החברה להגנת הטבע (`scripts/fetch-spni-updates.mjs`), מעדכנת את `public/data/updates.json`, ואם השתנה – מבצעת commit, בונה ודוחפת לענף `gh-pages`. האפליקציה מושכת את הקובץ בכל פתיחה/חזרה למסך ומסמנת פריטים חדשים ב"חדש".
- **מזג אוויר**: מתרענן בכל חזרה למסך וכל 10–20 דקות.

## פריסה

- **GitHub Pages (מענף)**: בכל push ל-`main` ה-workflow `.github/workflows/deploy-pages.yml` בונה ודוחף את `dist/` לענף `gh-pages`. בהגדרות: Settings → Pages → Source: **Deploy from a branch** → Branch: **gh-pages** / (root). הכתובת: `https://<user>.github.io/shvilisrael/`. ה-`base: './'` ב-Vite מאפשר הרצה מכל נתיב.
- בלי Actions בכלל: `npm run build` ואז לדחוף את תוכן `dist/` לענף `gh-pages` (ראו `npm run publish:gh-pages`).
- **Netlify / Vercel / Cloudflare Pages**: build command `npm run build`, output `dist`.
- חובה HTTPS כדי ש-GPS, מצפן ו-Service Worker יעבדו.

## מקורות נתונים ורישיונות

- **מפות**: [Israel Hiking Map](https://israelhiking.osm.org.il) (אריחים CC BY-NC-SA 3.0, לשימוש פרטי), OpenStreetMap (ODbL), OpenTopoMap.
- **תוואי השביל**: OpenStreetMap relation 282071 דרך Overpass API (מורד לפי בקשת המשתמש ונשמר במכשיר).
- **מזג אוויר**: [Open-Meteo](https://open-meteo.com) (ללא מפתח, שימוש לא-מסחרי).
- **תמונות**: Wikimedia Commons ברישיונות חופשיים; קרדיט מוצג על כל תמונה.
- **המדריך הרשמי**: [החברה להגנת הטבע – שביל ישראל](https://www.teva.org.il/israel-national-trail) – 56 מקטעים, מלאכי השביל (ללא פרטי קשר – קישור לעמוד הרשמי), עדכוני תוואי, מדריכי הכנה. נשלף ב-2026-11-08 (`src/data/spni/`).
- **מידע משלים**: רשות הטבע והגנים, ויקיפדיה/ויקימסע, קהילות השביליסטים ומדריכים מקוונים. ראו `docs/research.md`.

> ⚠️ המידע נאסף ממקורות ציבוריים ועשוי להשתנות (שינויי תוואי, סגירות ביטחוניות, שטחי אש, מחירים, מים בחניונים). לפני היציאה יש לאמת מול המפות והאתרים הרשמיים. האחריות על הבטיחות היא של המטייל.
